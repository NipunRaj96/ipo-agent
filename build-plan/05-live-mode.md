# Phase 5: Live mode

- Day 1, day 2: daily verdict update.
- Day 3: poll subscription every few minutes until the broker cut-off. Bids can be revised or cancelled until close, so the verdict can change late.
- Caveat: broker cut-offs (Zerodha, Groww) can be earlier than the official close, and large QIB bids often land in the final minutes.
- Output: Telegram message with apply / skip / abstain, probability, gain range, expected value, short explanation.
